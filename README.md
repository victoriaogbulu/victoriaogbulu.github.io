# Victoria Ogbulu — Portfolio

A single-page portfolio and introduction site for Victoria Ogbulu, multi-disciplinary designer.

## Highlights

- Animated glassmorphic hero wordmark (handwritten stroke reveal → full-colour logo) over a looping background video
- Scroll-docking logo that settles into the top navigation
- Accordion work showcase (Websites, Apps, Digital Ads, Global Campaigns) with masonry galleries and a full-screen lightbox (keyboard + swipe navigation)
- Auto-scrolling testimonials carousel with read-more quotes and arrow navigation
- Fixed-attachment parallax section background and animated section dividers

## Built with

Plain HTML, CSS, and vanilla JavaScript — no build step. Open `index.html` in a browser to view.

## Structure

- `index.html` — the entire site (markup, styles, and scripts)
- `Work/` — project images, grouped by category
- media assets (logos, background video, glass logo art) live alongside `index.html`
